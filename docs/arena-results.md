# Arena results: how the knowledge models compare

Generated by `npm run arena` (2026-10-08): 3 random seeds x 500 simulated learners per world, 236 s.

**Read this first.** These learners are SIMULATED (`server/scripts/arena/sim.js`). Each world switches certain behaviours of the hidden true skill on or off, so we can check that each model idea helps when its effect exists and does not hurt when it does not. The numbers say nothing about how good any model would be on REAL people; that needs the real logs (`npm run arena -- --source mongo`).

How to read the tables: every attempt is predicted before its result is learned, on learners the model never trained on. Lower log-loss is better (always guessing 50% scores 0.693); higher AUC is better; the calibration gap is how far "70%" is from the real success rate on average (lower is better). The last column is the average per-learner log-loss gain over today's Elo, with its uncertainty (a gain above about twice the uncertainty is a real difference, not luck).

| world | what is switched on in the true learners |
|---|---|
| W0-static | learning no, forgetting no, problems train one skill, independent skills, problem noise 60, session mood 0, 0% of the secondary skill tags the models see are wrong |
| W1-learning | learning yes, forgetting no, problems train one skill, independent skills, problem noise 60, session mood 0, 0% of the secondary skill tags the models see are wrong |
| W2-multiskill | learning yes, forgetting no, problems train several skills, independent skills, problem noise 60, session mood 0, 0% of the secondary skill tags the models see are wrong |
| W3-forgetting | learning yes, forgetting yes (half-life 12 days), problems train one skill, independent skills, problem noise 60, session mood 0, 0% of the secondary skill tags the models see are wrong |
| W4-realistic | learning yes, forgetting yes (half-life 25 days), problems train several skills, skills correlated (an overall ability), problem noise 120, session mood 40, 30% of the secondary skill tags the models see are wrong |
